# Phishing Email Detection Model

## Overview

This project uses Machine Learning and Scikit-learn to classify emails as either:

- Phishing
- Safe

The model is trained on a dataset of phishing and legitimate emails and uses TF-IDF feature extraction with a Naive Bayes classifier.

## Features

- Email text analysis
- Phishing keyword detection
- TF-IDF feature extraction
- Machine Learning classification
- Accuracy calculation
- Confusion Matrix display
